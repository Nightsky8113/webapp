# 画像アップロードと表示の流れ

## 📍 現在の実装状況

### ✅ 実装済み

1. **画像アップロード機能**
   - `src/services/storageService.js` - 画像をSupabase Storageにアップロード
   - アップロード成功時に画像URLを取得可能

2. **画像表示機能**
   - `StoreDetailPage` - 店舗詳細ページでチラシ画像を表示
   - `StoreCard` - 店舗一覧でサムネイル画像を表示

### ❌ 未実装（次のステップ）

1. **データベースとの統合**
   - アップロードした画像URLを`flyers`テーブルに保存する機能

2. **アップロードUI**
   - 画像をアップロードするフォームページ

---

## 🔄 画像が表示されるまでの流れ

### 現在の仕組み

```
1. データベースからチラシ情報を取得
   ↓
   flyers.image_url と flyers.thumbnail_url を読み取り
   ↓
2. StoreDetailPage / StoreCard で画像を表示
```

### アップロード後の流れ（実装が必要）

```
1. 画像をアップロード（storageService.js）
   ↓
   Supabase Storageに保存
   ↓
2. 取得したURLをデータベースに保存（未実装）
   ↓
   flyers.image_url と flyers.thumbnail_url に保存
   ↓
3. 既存の表示機能で自動表示
```

## 📋 画像が表示される場所

### 1. 店舗詳細ページ（`StoreDetailPage`）

**表示箇所**: `/store/{storeId}`

**取得元**: `flyers.image_url`
- `src/pages/StoreDetailPage.js` の81行目で取得
- `src/templates/pages/store-detail-page.html` で表示

**表示内容**:
- チラシのフルサイズ画像
- Lightbox2で拡大表示可能

### 2. 店舗カード（`StoreCard`）

**表示箇所**: 
- ホームページ（今日更新されたチラシ）
- 近くの店舗ページ（`StoresPage`）
- ジャンル別店舗ページ（`GenreStoresPage`）

**取得元**: `flyers.thumbnail_url`
- `src/components/StoreCard.js` の20行目で取得
- `src/templates/components/store-card.html` で表示

**表示内容**:
- チラシのサムネイル画像
- クリックで店舗詳細ページに遷移

## 🎯 次のステップで実装する必要がある機能

### 1. データベース統合機能

アップロードした画像URLを`flyers`テーブルに保存する機能を追加。

```javascript
// 実装イメージ
import { uploadFlyerImage } from './services/storageService.js';
import { supabase } from './services/supabase.js';

// 画像をアップロード
const result = await uploadFlyerImage(file, storeId);
if (result.success) {
    // データベースにURLを保存
    await supabase
        .from('flyers')
        .insert({
            store_id: storeId,
            image_url: result.url,
            thumbnail_url: result.url, // またはサムネイルURL
            is_latest: true,
            // ...
        });
}
```

### 2. アップロードUIページ（オプション）

画像をアップロードするためのフォームページを追加。

- `/admin/upload` - 管理者用アップロードページ
- 店舗選択
- ファイル選択
- アップロード実行
- アップロード済み画像の一覧表示

## ✅ まとめ

**質問への回答**:
> 「アップロードした画像のURLは取得できたけどどこに表示されるようになるの？」

**答え**:
- アップロードした画像URLを`flyers`テーブルの`image_url`/`thumbnail_url`に保存すれば、既存の表示機能で自動的に表示されます
- **表示場所**:
  - 店舗詳細ページ（`/store/{storeId}`） - フルサイズ画像
  - 店舗カード（一覧表示） - サムネイル画像

**実装が必要なもの**:
1. アップロードしたURLをデータベースに保存する機能
2. アップロードUI（フォームページ）

これらを実装すれば、アップロードした画像が自動的に表示されるようになります。
