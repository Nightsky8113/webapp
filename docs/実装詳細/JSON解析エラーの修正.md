# JSON解析エラーの修正

## 🔴 問題

画像をアップロードしてOCR処理を実行した際、以下のエラーが発生：

```
JSON解析エラー: SyntaxError: Unterminated string in JSON at position 4024
```

## 🔍 原因

1. **レスポンスが長すぎる**: Gemini APIからのレスポンスが`maxOutputTokens`の制限を超えて途中で切れている
2. **不完全なJSON**: JSON文字列が途中で終了している（"Unterminated string"）
3. **特殊文字の問題**: 商品名や説明に特殊文字が含まれ、JSONエスケープが不完全

## ✅ 修正内容

### 1. maxOutputTokensを増加

**変更前**: 2000トークン
**変更後**: 4000トークン

より長いレスポンスに対応できるようにしました。

```javascript
generationConfig: {
    temperature: 0.3,
    maxOutputTokens: 4000, // 2000から4000に増加
    responseMimeType: 'application/json'
}
```

### 2. JSON修復機能を追加

不完全なJSON文字列から有効な部分を抽出する機能を追加しました。

- 最初の `[` から開始
- 最後の完全な `]` までを抽出
- 文字列リテラル内の特殊文字を考慮

### 3. エラーハンドリングの改善

エラーが発生した場合、以下の詳細情報をログに出力：

- エラーメッセージ
- JSONコンテンツの最初の500文字
- JSONコンテンツの最後の500文字

これにより、問題の原因を特定しやすくなります。

### 4. JSON前処理の改善

以下の前処理を追加：

1. コードブロック（```json ... ```）の除去
2. 前後の空白・改行の除去
3. JSON修復処理

## 📋 実装ファイル

- `src/services/geminiService.js`

## 🎯 期待される効果

1. **長いレスポンスに対応**: より多くの商品情報を一度に処理可能
2. **不完全なJSONの処理**: 途中で切れたJSONでも、有効な部分を抽出して処理
3. **デバッグの容易化**: エラー発生時に詳細な情報を確認可能

## 🧪 テスト方法

1. 画像をアップロード
2. OCR処理を実行
3. JSON解析エラーが発生しないことを確認
4. 複数の商品が抽出されることを確認

## 📝 今後の改善案

もし問題が続く場合、以下の改善を検討できます：

1. **OCRテキストの分割**: 長いOCRテキストを複数に分割して処理
2. **ストリーミング処理**: Gemini APIのストリーミング機能を活用
3. **再試行ロジック**: エラー発生時に自動的にリトライ
