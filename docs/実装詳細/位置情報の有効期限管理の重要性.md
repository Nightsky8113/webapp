# 位置情報の有効期限管理の重要性

## 問題点

現在の実装では、LocalStorageに保存された位置情報に有効期限がないため、以下の問題が発生します：

### 1. 古い位置情報が使われる

- ユーザーが前回訪問時に東京にいた
- LocalStorageに「東京」の位置情報が保存される
- 次回、ユーザーが大阪に移動して訪問
- しかし、LocalStorageにはまだ「東京」の位置情報が残っている
- 結果：距離計算が「東京」基準になってしまい、正確ではない

### 2. 実際の使用例

```
1. ユーザーが自宅（東京）でウェルカムページを開く
   → 位置情報: { lat: 35.6812, lng: 139.7671 } をLocalStorageに保存

2. ユーザーが外出して、カフェ（大阪）でウェルカムページを開く
   → LocalStorageから古い位置情報（東京）を取得
   → 距離計算が「東京」基準になる
   → 大阪の店舗までの距離が正確ではない！
```

## 解決策

### 解決策1: 位置情報に有効期限を設定

位置情報と一緒にタイムスタンプも保存し、一定時間（例：30分）経過したら無効とみなす。

```javascript
// 位置情報を保存する際にタイムスタンプも一緒に保存
const locationData = {
    lat: 35.6812,
    lng: 139.7671,
    timestamp: Date.now() // 保存時刻を記録
};
saveToLocalStorage('userLocation', locationData);

// 位置情報を取得する際に有効期限をチェック
const LOCATION_EXPIRY = 30 * 60 * 1000; // 30分

function getCachedLocation() {
    const cached = getFromLocalStorage('userLocation');
    if (!cached || !cached.timestamp) {
        return null; // キャッシュなし
    }
    
    const age = Date.now() - cached.timestamp;
    if (age > LOCATION_EXPIRY) {
        return null; // 有効期限切れ
    }
    
    return { lat: cached.lat, lng: cached.lng };
}
```

### 解決策2: URLパラメータを最優先

URLパラメータがある場合はそれを優先し、LocalStorageは最後の手段として使う。

```javascript
// 優先順位:
// 1. URLパラメータ（最も信頼できる）
// 2. 有効期限内のLocalStorageキャッシュ（30分以内）
// 3. 位置情報なし（距離を表示しない）

if (queryParams.lat && queryParams.lng) {
    // URLパラメータを最優先
    userLocation = {
        lat: parseFloat(queryParams.lat),
        lng: parseFloat(queryParams.lng)
    };
} else {
    // LocalStorageから取得（有効期限チェック付き）
    const cachedLocation = getCachedLocation(); // 有効期限をチェック
    if (cachedLocation) {
        userLocation = cachedLocation;
    }
}
```

### 解決策3: ウェルカムページから遷移する際に位置情報を取得

ウェルカムページから店舗カードをクリックした際に、現在の位置情報を取得してURLに含める。

```javascript
attachStoreCardEvents(todayContainer, async (storeId) => {
    // URLから位置情報を取得（存在する場合）
    const urlParams = new URLSearchParams(window.location.hash.split('?')[1]);
    let lat = urlParams.get('lat');
    let lng = urlParams.get('lng');
    
    // 位置情報がない場合、現在の位置情報を取得
    if (!lat || !lng) {
        try {
            const { requestUserLocation } = await import('../utils/location.js');
            const currentLocation = await requestUserLocation();
            lat = currentLocation.lat;
            lng = currentLocation.lng;
        } catch (error) {
            // 位置情報が取得できない場合は位置情報なしで遷移
        }
    }
    
    if (lat && lng) {
        window.location.hash = `/store/${storeId}?lat=${lat}&lng=${lng}`;
    } else {
        window.location.hash = `/store/${storeId}`;
    }
});
```

## 推奨実装

**解決策1 + 解決策2 + 解決策3 の組み合わせ**が最適です：

1. **位置情報に有効期限を設定**（30分）
2. **URLパラメータを最優先**
3. **有効期限内のLocalStorageキャッシュをフォールバックとして使用**
4. **ウェルカムページから遷移する際に位置情報を取得**

これにより：
- 最新の位置情報が保証される
- 位置情報取得のパフォーマンスも向上（有効期限内なら再取得不要）
- ユーザー体験も向上

## 実装の詳細

### 1. 位置情報の保存形式を変更

```javascript
// 変更前
saveToLocalStorage('userLocation', { lat: 35.6812, lng: 139.7671 });

// 変更後
saveToLocalStorage('userLocation', {
    lat: 35.6812,
    lng: 139.7671,
    timestamp: Date.now()
});
```

### 2. 有効期限チェック付きの取得関数

```javascript
const LOCATION_EXPIRY = 30 * 60 * 1000; // 30分

export function getCachedLocation() {
    const cached = getFromLocalStorage('userLocation');
    if (!cached) {
        return null;
    }
    
    // 旧形式との互換性（timestampがない場合）
    if (!cached.timestamp) {
        return null; // タイムスタンプがない場合は無効
    }
    
    const age = Date.now() - cached.timestamp;
    if (age > LOCATION_EXPIRY) {
        // 有効期限切れの場合は削除
        localStorage.removeItem('userLocation');
        return null;
    }
    
    return { lat: cached.lat, lng: cached.lng };
}
```

### 3. router.jsでの優先順位

```javascript
// 優先順位:
// 1. URLパラメータ（最も信頼できる、最新の位置情報）
// 2. 有効期限内のLocalStorageキャッシュ（フォールバック）
// 3. 位置情報なし

if (queryParams.lat && queryParams.lng) {
    userLocation = {
        lat: parseFloat(queryParams.lat),
        lng: parseFloat(queryParams.lng)
    };
} else {
    const { getCachedLocation } = await import('./utils/location.js');
    userLocation = getCachedLocation(); // 有効期限チェック付き
}
```

## まとめ

位置情報の有効期限管理は重要です。ユーザーが移動している可能性を考慮し、常に最新の位置情報を使用できるようにする必要があります。

**推奨実装**:
- 位置情報に30分の有効期限を設定
- URLパラメータを最優先
- 有効期限内のLocalStorageキャッシュをフォールバックとして使用
- ウェルカムページから遷移する際に現在の位置情報を取得
