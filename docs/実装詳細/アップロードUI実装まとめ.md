## 🎯 実装した機能

### ファイルプレビュー

選択した画像ファイルをアップロード前にプレビュー表示：
- 画像表示
- ファイル名表示
- ファイルサイズ表示

### アップロード処理

1. フォーム送信時：
   - 店舗選択の検証
   - ファイル選択の検証
   - アップロード開始

2. アップロード中：
   - ボタンを無効化（重複送信防止）
   - 「アップロード中...」メッセージ表示

3. アップロード完了：
   - 成功/エラーメッセージ表示
   - フォームをリセット
   - プレビューをクリア

### エラーハンドリング

- 店舗未選択時のエラー表示
- ファイル未選択時のエラー表示
- アップロード失敗時のエラー表示
- ファイルサイズ・形式の検証（`storageService.js`で実装済み）

## 📋 使用方法

### ページにアクセス

```
http://localhost:3000/#/admin/upload
```

### アップロード手順

1. **店舗を選択**
   - ドロップダウンから店舗を選択

2. **画像ファイルを選択**
   - 「画像ファイルを選択」ボタンをクリック
   - JPEG, PNG, WebP, GIF形式の画像を選択
   - 最大サイズ: 50MB

3. **プレビューを確認**
   - 選択した画像がプレビュー表示されます

4. **アップロード実行**
   - 「アップロード」ボタンをクリック
   - アップロード完了まで待機

5. **結果確認**
   - 成功メッセージが表示されます
   - アップロードした画像は自動的にデータベースに保存され、既存の表示機能で自動的に表示されます

---

## 🔄 アップロード後の流れ

```
1. 画像をアップロード
   ↓
2. Supabase Storageに保存
   ↓
3. データベース（flyersテーブル）にURLを保存
   ↓
4. 既存の表示機能で自動表示
   - 店舗詳細ページ（/store/{storeId}）
   - 店舗カード（一覧表示）
```
