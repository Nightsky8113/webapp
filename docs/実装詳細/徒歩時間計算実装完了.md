# 徒歩時間計算機能 実装完了

OSRM APIを使用した無料の徒歩時間計算機能を実装しました。

## ✅ 実装内容

### 1. 徒歩時間計算サービス（`src/services/walkingTimeService.js`）

**機能**:
- OSRM APIを使用して最寄り駅から店舗までの徒歩時間を計算
- 計算結果をデータベースの`summary_walk_minutes`に自動保存
- 既に保存されている場合はAPIを呼ばずにデータベースから取得
- 複数店舗の一括計算機能

**主要な関数**:
- `calculateWalkingRoute()` - OSRM APIでルートと時間を取得
- `getWalkingTime()` - 店舗の徒歩時間を取得（DBに保存されている場合はそれを使用）
- `batchUpdateWalkingTimes()` - 複数店舗の徒歩時間を一括計算

### 2. 表示機能の統合

**統合したページ**:
- **StoreDetailPage** - 店舗詳細ページに徒歩時間を表示
- **StoreCard** - 店舗カードに徒歩時間を表示

**表示形式**:
- 「東京駅から徒歩5分」のように表示
- 徒歩時間が取得できない場合は最寄り駅名のみ表示

### 3. データフロー

```
1. ページが読み込まれる
   ↓
2. getWalkingTime(storeId) が呼ばれる
   ↓
3. データベースをチェック（summary_walk_minutes）
   ↓
   存在する → その値を返す（API呼び出しなし）✅
   ↓
   存在しない → OSRM APIを呼び出す
   ↓
4. 徒歩時間を計算（秒 → 分に変換）
   ↓
5. データベースに保存（summary_walk_minutes）
   ↓
6. 次回以降はデータベースから取得（API呼び出しなし）✅
```

## 🔧 使用方法

### 自動取得（推奨）

徒歩時間は、店舗詳細ページや店舗カードが表示される際に自動的に取得されます。

1. 初回表示時: APIを呼び出して計算し、データベースに保存
2. 2回目以降: データベースから取得（API呼び出しなし）

### 手動で再計算する場合

JavaScriptコンソールから実行:

```javascript
import { getWalkingTime } from './src/services/walkingTimeService.js';

// 店舗ID 1の徒歩時間を再計算
const walkMinutes = await getWalkingTime(1, true); // 第2引数: true = 強制再計算
```

### 複数店舗を一括計算する場合

```javascript
import { batchUpdateWalkingTimes } from './src/services/walkingTimeService.js';

// 店舗ID 1, 2, 3の徒歩時間を一括計算
const results = await batchUpdateWalkingTimes([1, 2, 3]);
console.log('成功:', results.success);
console.log('失敗:', results.failed);
```

## 📊 必要なデータ

徒歩時間を計算するには、以下のデータが必要です：

1. **最寄り駅の緯度・経度** (`nearest_station_lat`, `nearest_station_lng`)
2. **店舗の緯度・経度** (`latitude`, `longitude`)

これらのデータがデータベースに登録されている場合、自動的に徒歩時間を計算します。

## ⚠️ 注意点

### APIレート制限

- OSRMのパブリックインスタンスは利用制限がある可能性があります
- 一括計算時は、リクエスト間に1秒待機する処理を実装済み

### エラーハンドリング

- APIが利用できない場合、徒歩時間は表示されません（最寄り駅名のみ表示）
- データベースに最寄り駅の位置情報がない場合、徒歩時間は計算できません

### データの正確性

- 徒歩時間は一度計算すれば基本的に変わりません
- 道路工事などでルートが変わる場合は、再計算が必要です
