# 画像アップロードとデータベース統合機能

## ✅ 実装完了

### 1. データベース保存機能

**`src/services/dataService.js`**に追加した機能：

- **`createFlyer(flyerData)`** - チラシを作成
  - 新しいチラシを`flyers`テーブルに保存
  - 同じ店舗の既存チラシの`is_latest`を自動で`false`に更新
  - キャッシュを自動クリア

- **`updateFlyer(flyerId, updateData)`** - チラシを更新
  - 既存のチラシを更新
  - `updated_at`を自動更新
  - キャッシュを自動クリア

### 2. 統合機能

**`src/services/storageService.js`**に追加した機能：

- **`uploadAndSaveFlyer(file, storeId, options)`** - 画像アップロード + データベース保存を一度に実行
  - 画像をSupabase Storageにアップロード
  - アップロードした画像URLを`flyers`テーブルに自動保存
  - エラーハンドリング付き

---

## 🎯 使用方法

### 方法1: 統合関数を使用（推奨）

画像アップロードとデータベース保存を一度に行う：

```javascript
import { uploadAndSaveFlyer } from './services/storageService.js';

const fileInput = document.getElementById('file-input');
const file = fileInput.files[0];
const storeId = 1;

const result = await uploadAndSaveFlyer(file, storeId, {
    is_latest: true,
    ocr_done: false
});

if (result.success) {
    console.log('アップロードと保存成功:', result.flyer);
    console.log('画像URL:', result.imageUrl);
    // これで既存の表示機能で自動的に画像が表示されます
} else {
    console.error('エラー:', result.error);
}
```

### 方法2: 個別に実行

画像アップロードとデータベース保存を別々に実行する：

```javascript
import { uploadFlyerImage } from './services/storageService.js';
import { createFlyer } from './services/dataService.js';

// 1. 画像をアップロード
const uploadResult = await uploadFlyerImage(file, storeId);

if (!uploadResult.success) {
    console.error('アップロード失敗:', uploadResult.error);
    return;
}

// 2. データベースに保存
const saveResult = await createFlyer({
    store_id: storeId,
    image_url: uploadResult.url,
    thumbnail_url: uploadResult.url,
    is_latest: true,
    ocr_done: false
});

if (saveResult.success) {
    console.log('保存成功:', saveResult.data);
} else {
    console.error('保存失敗:', saveResult.error);
}
```

### 方法3: 既存チラシを更新

既存のチラシを更新する場合：

```javascript
import { uploadFlyerImage } from './services/storageService.js';
import { updateFlyer } from './services/dataService.js';

// 既存のチラシ情報を取得
const existingFlyer = await getLatestFlyerByStoreId(storeId);

// 新しい画像をアップロード（既存のパスを使用）
const uploadResult = await uploadFlyerImage(file, storeId, {
    oldPath: existingFlyer.image_path // 既存のパスを指定
});

if (uploadResult.success) {
    // チラシを更新
    await updateFlyer(existingFlyer.id, {
        image_url: uploadResult.url,
        thumbnail_url: uploadResult.url
    });
}
```

## 📋 関数の詳細

### `createFlyer(flyerData)`

**パラメータ**:
- `store_id` (number) - 店舗ID（必須）
- `image_url` (string) - 画像URL（必須）
- `thumbnail_url` (string) - サムネイルURL（省略可能、デフォルト: `image_url`）
- `is_latest` (boolean) - 最新フラグ（デフォルト: `true`）
- `ocr_done` (boolean) - OCR処理済みフラグ（デフォルト: `false`）

**戻り値**:
```javascript
{
    success: boolean,
    data?: Object,  // 作成されたチラシデータ
    error?: string
}
```

**動作**:
- 新しいチラシを`flyers`テーブルに作成
- `is_latest`が`true`の場合、同じ店舗の既存チラシの`is_latest`を`false`に更新
- キャッシュを自動クリア

### `updateFlyer(flyerId, updateData)`

**パラメータ**:
- `flyerId` (number) - チラシID
- `updateData` (Object) - 更新するデータ

**戻り値**:
```javascript
{
    success: boolean,
    data?: Object,  // 更新されたチラシデータ
    error?: string
}
```

**動作**:
- 既存のチラシを更新
- `updated_at`を自動更新
- キャッシュを自動クリア

### `uploadAndSaveFlyer(file, storeId, options)`

**パラメータ**:
- `file` (File) - アップロードする画像ファイル
- `storeId` (number) - 店舗ID
- `options` (Object) - オプション
  - `oldPath` (string) - 既存のファイルパス（更新時）
  - `thumbnailUrl` (string) - サムネイルURL（省略可能）
  - `is_latest` (boolean) - 最新フラグ（デフォルト: `true`）
  - `ocr_done` (boolean) - OCR処理済みフラグ（デフォルト: `false`）

**戻り値**:
```javascript
{
    success: boolean,
    flyer?: Object,      // 作成されたチラシデータ
    imageUrl?: string,   // 画像URL
    imagePath?: string,  // 画像パス
    error?: string
}
```

**動作**:
- 画像をSupabase Storageにアップロード
- アップロードした画像URLを`flyers`テーブルに自動保存
- エラー時は適切にエラーを返す

## ✅ 画像表示までの流れ

1. **画像をアップロード + データベースに保存**
   ```javascript
   await uploadAndSaveFlyer(file, storeId);
   ```

2. **自動的に表示される**
   - 店舗詳細ページ（`/store/{storeId}`） - `flyers.image_url`から取得
   - 店舗カード（一覧表示） - `flyers.thumbnail_url`から取得

3. **キャッシュが自動クリアされる**
   - 新しいデータが即座に反映される

## 🔄 データベースの状態

### 新規チラシを作成した場合

```
店舗1の既存チラシ: is_latest = false（自動更新）
店舗1の新しいチラシ: is_latest = true（新規作成）
```

### 既存チラシを更新した場合

```
既存チラシ: is_latest = true（そのまま）
更新内容: image_url, thumbnail_url, updated_at（更新）
```

## 💡 使用例

### 基本的なアップロード

```javascript
const file = document.getElementById('file-input').files[0];
const storeId = 1;

const result = await uploadAndSaveFlyer(file, storeId);
if (result.success) {
    alert('アップロード成功！');
    // ページをリロードまたは表示を更新
    window.location.reload();
}
```

### エラーハンドリング付き

```javascript
const result = await uploadAndSaveFlyer(file, storeId);

if (!result.success) {
    if (result.error.includes('ファイルサイズ')) {
        alert('ファイルサイズが大きすぎます。');
    } else if (result.error.includes('ファイル形式')) {
        alert('対応していないファイル形式です。');
    } else {
        alert('アップロードに失敗しました: ' + result.error);
    }
    return;
}

// 成功時の処理
console.log('チラシID:', result.flyer.id);
console.log('画像URL:', result.imageUrl);
```
