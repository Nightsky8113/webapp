# 徒歩時間計算の無料実装案

最寄り駅からの徒歩時間を無料で取得し、一度取得したデータをデータベースに保存して再利用する実装案です。

## 📋 概要

徒歩時間は一度取得すれば基本的に変わらないため、データベースに保存して使いまわすことで、API呼び出しを最小限に抑えることができます。

## 🔍 無料で利用可能なAPI

### 1. OSRM (Open Source Routing Machine) ⭐ 推奨

**特徴**:
- ✅ **完全無料**
- ✅ **商用利用可能**
- ✅ **APIキー不要**
- ✅ **オープンソース**

**パブリックインスタンス**:
- `https://router.project-osrm.org/route/v1/walking/{coordinates}`
- 1日あたりのリクエスト制限あり（詳細不明、通常は十分）

**API仕様**:
```
GET https://router.project-osrm.org/route/v1/walking/{経度},{緯度};{経度},{緯度}?overview=false&steps=true
```

**レスポンス例**:
```json
{
  "routes": [{
    "distance": 523.4,  // メートル
    "duration": 376.2   // 秒
  }]
}
```

**徒歩時間の計算**:
- `duration / 60` で分単位に変換
- 例: 376.2秒 = 約6.3分 → 7分（切り上げ）

**注意点**:
- パブリックインスタンスは利用制限がある可能性
- より安定した運用にはセルフホスティングも可能

### 2. OpenRouteService

**特徴**:
- ✅ **無料枠**: 1日2,000リクエストまで無料
- ✅ **APIキー必要**（無料で取得可能）
- ✅ **商用利用可能**（無料枠内）

**API仕様**:
```
GET https://api.openrouteservice.org/v2/directions/foot-walking?api_key={API_KEY}&start={経度},{緯度}&end={経度},{緯度}
```

**メリット**:
- 無料枠が大きく、個人プロジェクトには十分
- ドキュメントが充実
- 安定したサービス

### 3. GraphHopper

**特徴**:
- ✅ **無料枠**: 1日500リクエストまで無料
- ✅ **APIキー必要**
- ⚠️ 無料枠がやや少ない

### 4. 簡易計算（不動産業界基準）

**計算式**:
- 80メートル = 1分
- 距離（m）÷ 80 = 分

**メリット**:
- API呼び出し不要
- 即座に計算可能

**デメリット**:
- 信号待ちや坂道を考慮しない
- 実際の道路ルートと異なる可能性

## 💡 推奨実装方法

### 方法A: OSRMを使用（完全無料）⭐

**メリット**:
- APIキー不要
- 完全無料
- 実装が簡単

**実装の流れ**:
1. 店舗登録時または管理者が手動で計算ボタンをクリック
2. 最寄り駅の緯度・経度と店舗の緯度・経度を取得
3. OSRM APIでルートを取得
4. 距離と時間を計算
5. データベースの`summary_walk_minutes`に保存
6. 次回以降はデータベースから取得

### 方法B: OpenRouteServiceを使用（無料枠あり）

**メリット**:
- 無料枠が大きい（1日2,000リクエスト）
- サービスが安定している

**実装の流れ**:
- 方法Aと同じ（APIエンドポイントとレスポンス形式が異なる）

## 📝 実装コード例

### `src/services/walkingTimeService.js`

```javascript
import { supabase } from './supabase.js';

/**
 * OSRM APIを使用して徒歩時間を計算する
 * @param {number} stationLat - 最寄り駅の緯度
 * @param {number} stationLng - 最寄り駅の経度
 * @param {number} storeLat - 店舗の緯度
 * @param {number} storeLng - 店舗の経度
 * @returns {Promise<number|null>} 徒歩時間（分）、取得できない場合はnull
 */
export async function calculateWalkingTime(stationLat, stationLng, storeLat, storeLng) {
    try {
        // OSRM APIエンドポイント
        const url = `https://router.project-osrm.org/route/v1/walking/${stationLng},${stationLat};${storeLng},${storeLat}?overview=false&steps=false`;
        
        const response = await fetch(url);
        
        if (!response.ok) {
            throw new Error(`HTTP error! status: ${response.status}`);
        }
        
        const data = await response.json();
        
        if (data.code !== 'Ok' || !data.routes || data.routes.length === 0) {
            console.warn('OSRM: ルートが見つかりませんでした');
            return null;
        }
        
        // durationは秒単位なので、分に変換して切り上げ
        const durationSeconds = data.routes[0].duration;
        const walkMinutes = Math.ceil(durationSeconds / 60);
        
        console.log(`OSRM: 徒歩時間 ${walkMinutes}分（${durationSeconds}秒）`);
        
        return walkMinutes;
    } catch (error) {
        console.error('徒歩時間計算エラー:', error);
        return null;
    }
}

/**
 * 店舗の徒歩時間を取得する（データベースに保存されている場合はそれを使用）
 * @param {number} storeId - 店舗ID
 * @param {boolean} forceRecalculate - trueの場合、データベースを無視して再計算
 * @returns {Promise<number|null>} 徒歩時間（分）、取得できない場合はnull
 */
export async function getWalkingTime(storeId, forceRecalculate = false) {
    // 店舗情報を取得
    const { data: store, error: storeError } = await supabase
        .from('stores')
        .select('summary_walk_minutes, nearest_station_lat, nearest_station_lng, latitude, longitude')
        .eq('id', storeId)
        .single();
    
    if (storeError || !store) {
        console.error('店舗取得エラー:', storeError);
        return null;
    }
    
    // 既に保存されている場合、再計算が要求されていない場合はその値を返す
    if (!forceRecalculate && store.summary_walk_minutes) {
        console.log(`店舗 ${storeId}: 保存済みの徒歩時間 ${store.summary_walk_minutes}分を使用`);
        return store.summary_walk_minutes;
    }
    
    // 最寄り駅の位置情報が必須
    if (!store.nearest_station_lat || !store.nearest_station_lng) {
        console.warn(`店舗 ${storeId}: 最寄り駅の位置情報がありません`);
        return null;
    }
    
    // 徒歩時間を計算
    const walkMinutes = await calculateWalkingTime(
        store.nearest_station_lat,
        store.nearest_station_lng,
        store.latitude,
        store.longitude
    );
    
    if (walkMinutes === null) {
        return null;
    }
    
    // データベースに保存
    const { error: updateError } = await supabase
        .from('stores')
        .update({ summary_walk_minutes: walkMinutes })
        .eq('id', storeId);
    
    if (updateError) {
        console.error('徒歩時間保存エラー:', updateError);
        // エラーが発生しても計算結果は返す
    } else {
        console.log(`店舗 ${storeId}: 徒歩時間 ${walkMinutes}分をデータベースに保存`);
    }
    
    return walkMinutes;
}

/**
 * 複数の店舗の徒歩時間を一括で計算・更新する
 * @param {Array<number>} storeIds - 店舗IDの配列
 * @returns {Promise<Object>} 結果 {success: Array, failed: Array}
 */
export async function batchUpdateWalkingTimes(storeIds) {
    const results = { success: [], failed: [] };
    
    for (const storeId of storeIds) {
        const walkMinutes = await getWalkingTime(storeId, true); // 強制再計算
        if (walkMinutes !== null) {
            results.success.push({ storeId, walkMinutes });
        } else {
            results.failed.push(storeId);
        }
        
        // APIレート制限を避けるため、1秒待機
        await new Promise(resolve => setTimeout(resolve, 1000));
    }
    
    return results;
}
```

### OpenRouteService版（代替案）

```javascript
/**
 * OpenRouteService APIを使用して徒歩時間を計算する
 * @param {number} stationLat - 最寄り駅の緯度
 * @param {number} stationLng - 最寄り駅の経度
 * @param {number} storeLat - 店舗の緯度
 * @param {number} storeLng - 店舗の経度
 * @param {string} apiKey - OpenRouteServiceのAPIキー（環境変数から取得）
 * @returns {Promise<number|null>} 徒歩時間（分）、取得できない場合はnull
 */
export async function calculateWalkingTimeWithOpenRouteService(stationLat, stationLng, storeLat, storeLng, apiKey) {
    try {
        const url = `https://api.openrouteservice.org/v2/directions/foot-walking?api_key=${apiKey}&start=${stationLng},${stationLat}&end=${storeLng},${storeLat}`;
        
        const response = await fetch(url);
        
        if (!response.ok) {
            throw new Error(`HTTP error! status: ${response.status}`);
        }
        
        const data = await response.json();
        
        if (!data.routes || data.routes.length === 0) {
            console.warn('OpenRouteService: ルートが見つかりませんでした');
            return null;
        }
        
        // durationは秒単位なので、分に変換して切り上げ
        const durationSeconds = data.routes[0].summary.duration;
        const walkMinutes = Math.ceil(durationSeconds / 60);
        
        console.log(`OpenRouteService: 徒歩時間 ${walkMinutes}分（${durationSeconds}秒）`);
        
        return walkMinutes;
    } catch (error) {
        console.error('徒歩時間計算エラー:', error);
        return null;
    }
}
```

## 🔄 データフロー

```
1. 店舗データに徒歩時間が必要な場合
   ↓
2. データベースをチェック（summary_walk_minutes）
   ↓
3. 存在する → その値を返す（API呼び出しなし）
   ↓
   存在しない → OSRM APIを呼び出す
   ↓
4. 徒歩時間を計算
   ↓
5. データベースに保存
   ↓
6. 次回以降はデータベースから取得
```

## ⚠️ 注意点

### APIレート制限

- **OSRM**: パブリックインスタンスは制限がある可能性
- **OpenRouteService**: 1日2,000リクエストまで無料
- **対策**: データベースに保存して再利用、リクエスト間に1秒待機

### データの正確性

- 道路工事などでルートが変わる可能性
- 定期的な再計算を検討（例: 半年ごと）

### エラーハンドリング

- APIが利用できない場合のフォールバック
- 簡易計算（80m = 1分）への切り替え
