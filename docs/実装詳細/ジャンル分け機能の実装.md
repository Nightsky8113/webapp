# ジャンル分け機能の実装

## ✅ 実装完了

OCRで抽出した商品にジャンル分け（ジャンルID）を設定できる機能を実装しました。

---

## 📋 実装内容

### 1. Gemini APIプロンプトの改善

**`src/services/geminiService.js`**を修正：

- 利用可能なジャンルリストをプロンプトに含める
- 各商品に最も適切なジャンルを選択するように指示
- `genre`フィールドを必須項目として指定

#### ジャンル一覧
- 精肉（ID: 1）
- 鮮魚（ID: 2）
- 野菜（ID: 3）
- 果物（ID: 4）
- 日用品（ID: 5）
- お菓子（ID: 6）
- 飲料（ID: 7）
- 冷凍食品（ID: 8）

### 2. ジャンル名からジャンルIDへのマッピング

**`src/services/ocrService.js`**を修正：

- ジャンルリストを取得
- ジャンル名からジャンルIDへのマッピングを作成
- 保存時にジャンル名をジャンルIDに変換

### 3. データベース保存時のジャンルID設定

商品情報を保存する際に、`genre_id`カラムにジャンルIDを設定するように修正。

## 🔧 実装の詳細

### Gemini APIプロンプトの変更点

**変更前**:
- カテゴリを任意の文字列として抽出
- ジャンルリストが提供されていない

**変更後**:
- 利用可能なジャンルリストをプロンプトに含める
- ジャンルは必須項目として指定
- ジャンル名は完全一致する必要があることを指示

### 保存処理の変更点

**変更前**:
```javascript
const itemsToInsert = items.map(item => ({
    flyer_id: flyerId,
    name: item.name,
    price: Math.round(item.price),
    // genre_idは設定されていない
}));
```

**変更後**:
```javascript
// ジャンルリストを取得してマッピングを作成
const genres = await getGenres();
const genreMap = new Map(genres.map(g => [g.name, g.id]));

const itemsToInsert = items.map(item => {
    const genreName = item.genre || item.category || '';
    const genreId = genreMap.get(genreName) || null;
    
    return {
        flyer_id: flyerId,
        name: item.name,
        genre_id: genreId, // ジャンルIDを設定
        price: Math.round(item.price),
    };
});
```

## 📝 処理フロー

1. **OCR処理**: 画像からテキストを抽出
2. **Gemini API処理**: 
   - ジャンルリストを取得
   - プロンプトにジャンルリストを含める
   - 商品情報を構造化（ジャンル名を含む）
3. **ジャンルIDマッピング**:
   - ジャンルリストを取得
   - ジャンル名からジャンルIDへのマッピングを作成
4. **データベース保存**:
   - ジャンル名をジャンルIDに変換
   - `genre_id`カラムにジャンルIDを設定して保存

## 🎯 期待される動作

### 例: 精肉の商品を抽出した場合

1. Gemini APIが「国産牛ロース」を抽出
2. ジャンルリストから「精肉」を選択
3. ジャンル名「精肉」が返される
4. 保存時にジャンル名「精肉」がジャンルID「1」に変換される
5. データベースに`genre_id: 1`として保存される

### 例: ジャンルが一致しない場合

- ジャンル名が見つからない場合、`genre_id`は`null`として保存される
- これは、AIが誤って分類した場合でもシステムがエラーにならないようにするため

## 📝 注意事項

- ジャンル名が完全一致しない場合（例：「精肉」と「精肉類」）、ジャンルIDは`null`になる
- この場合、ユーザーが手動でジャンルを修正する必要がある
- 将来的には、ジャンル名の正規化や類似度マッチングを追加することも可能
