# 店舗詳細ページの地図実装

## 実装内容

### 1. 距離表示の削除

- **店舗詳細ページから距離表示を削除**
  - 距離表示は最大6件の店舗を表示しているページ（位置情報検索ページ）のみに表示
  - 店舗詳細ページでは距離表示を削除

### 2. 地図の追加

- **店舗詳細ページに地図を追加**
  - 店舗の位置にピンを表示
  - 位置情報が利用可能な場合、現在地にもピンを表示
  - 位置情報が利用可能な場合、地図の表示範囲を店舗と現在地の両方を含むように自動調整

### 3. 位置情報取得処理

- **ウェルカムページから遷移する際の位置情報取得**
  - 店舗カードをクリックした際に、位置情報を取得を試みる
  - 位置情報が取得できた場合、URLパラメータに含めて遷移
  - 位置情報の権限が拒否された場合、位置情報なしで遷移（店舗のピンのみ表示）

### 2. 地図の追加

#### テンプレートに地図コンテナを追加
```html
<!-- 地図 -->
${if:hasStoreLocation}
<div class="store-detail-card">
  <div class="p-6">
    <h2 class="text-2xl font-bold mb-4 flex items-center gap-2">
      <span>🗺️</span>
      店舗の位置
    </h2>
```

#### 地図の初期化処理
```javascript
// 店舗の位置情報を取得
const store = await getStoreById(storeId);

// URLパラメータから位置情報を取得
const urlParams = new URLSearchParams(window.location.hash.split('?')[1]);
const userLat = urlParams.get('lat') ? parseFloat(urlParams.get('lat')) : null;
const userLng = urlParams.get('lng') ? parseFloat(urlParams.get('lng')) : null;

// 地図を初期化
const map = L.map('store-detail-map').setView([store.latitude, store.longitude], 15);

// 店舗マーカーを追加
L.marker([store.latitude, store.longitude])
    .addTo(map)
    .bindPopup(`<div class="text-center"><strong>${store.name}</strong></div>`)
    .openPopup();

// 位置情報がある場合、現在地のマーカーを追加
if (userLat && userLng) {
    L.marker([userLat, userLng])
        .addTo(map)
        .bindPopup('あなたの現在地');

    // 地図の表示範囲を調整
    const bounds = L.latLngBounds(
        [[store.latitude, store.longitude], [userLat, userLng]]
    );
    map.fitBounds(bounds, { padding: [50, 50] });
}
```

### 3. 位置情報取得処理

#### ウェルカムページから遷移する際の処理
```javascript
attachStoreCardEvents(todayContainer, async (storeId) => {
    // URLから位置情報を取得
    const urlParams = new URLSearchParams(window.location.hash.split('?')[1]);
    let lat = urlParams.get('lat');
    let lng = urlParams.get('lng');
    
    // 位置情報がない場合、現在の位置情報を取得を試みる
    if (!lat || !lng) {
        try {
            const { requestUserLocation } = await import('../utils/location.js');
            const currentLocation = await requestUserLocation();
            lat = currentLocation.lat.toString();
            lng = currentLocation.lng.toString();
        } catch (error) {
            // 位置情報の取得に失敗した場合（権限拒否など）は位置情報なしで遷移
            console.warn('位置情報の取得に失敗しました:', error.message);
        }
    }
    
    if (lat && lng) {
        window.location.hash = `/store/${storeId}?lat=${lat}&lng=${lng}`;
    } else {
        window.location.hash = `/store/${storeId}`;
    }
});
```

## 動作確認

### ケース1: 位置情報検索ページから遷移
- URLに位置情報が含まれている
- 地図に店舗と現在地の両方のピンが表示される
- 地図の表示範囲が自動調整される

### ケース2: ウェルカムページから遷移（位置情報取得成功）
- 位置情報を取得してURLに含める
- 地図に店舗と現在地の両方のピンが表示される
- 地図の表示範囲が自動調整される

### ケース3: ウェルカムページから遷移（位置情報取得失敗）
- 位置情報の権限が拒否された場合
- 位置情報なしで遷移
- 地図に店舗のピンのみ表示される

---

## 注意事項

- 店舗に位置情報（`latitude`, `longitude`）がない場合、地図は表示されません
- 位置情報が取得できない場合でも、店舗のピンは表示されます
- 地図の初期化は`attachStoreDetailPageEvents`関数内で行われます
