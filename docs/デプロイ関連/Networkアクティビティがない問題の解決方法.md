# Networkアクティビティがない問題の解決方法

## 🔍 問題

Vercel上でNetworkタブを開いてもアクティビティが何もない

この問題は、**JavaScriptファイルが全く読み込まれていない**、または**HTMLファイル自体が読み込まれていない**ことを示しています。

---

## 考えられる原因と確認方法

### 1. HTMLファイル自体が読み込まれていない（404エラー）

**確認方法**:
1. ブラウザで直接URLにアクセス: `https://your-app.vercel.app/`
2. ページのソースを表示（右クリック → ページのソースを表示）
3. HTMLが表示されない場合、404エラーが発生している可能性

**解決方法**:
- Vercelのデプロイログを確認
- `vercel.json`の`rewrites`設定が正しいか確認

---

### 2. JavaScriptファイルが読み込まれていない

**確認方法**:
1. 開発者ツール（F12）を開く
2. **Consoleタブ**で以下を確認:
   - `✅ HTMLが読み込まれました` が表示されるか
   - `✅ インラインスクリプトが実行されました` が表示されるか
   - `✅ main.jsが読み込まれました` が表示されるか
   - エラーメッセージが表示されているか

3. **Networkタブ**で以下を確認:
   - `index.html`が読み込まれているか（Status Code: 200）
   - JavaScriptファイル（`index-*.js`）が読み込まれているか
   - CSSファイル（`index-*.css`）が読み込まれているか
   - CDNリソース（Leaflet、UnoCSS）が読み込まれているか

**考えられる原因**:
- JavaScriptファイルのパスが間違っている
- CSPエラーでスクリプトがブロックされている
- ビルド済みファイルが正しくデプロイされていない

---

### 3. ブラウザのキャッシュ

**確認方法**:
1. ハードリフレッシュを実行:
   - **Windows**: `Ctrl + Shift + R` または `Ctrl + F5`
   - **Mac**: `Cmd + Shift + R`
2. シークレットモード/プライベートモードで開く

---

### 4. CSPエラーでスクリプトがブロックされている

**確認方法**:
1. ConsoleタブでCSPエラーを確認
2. エラーメッセージに`Content Security Policy`が含まれているか確認

**解決方法**:
- `vercel.json`のCSP設定を確認
- `script-src`に必要なドメインが含まれているか確認

---

### 5. Vercelのデプロイ設定

**確認方法**:
1. Vercelダッシュボードにアクセス
2. デプロイ履歴を確認
3. ビルドログでエラーがないか確認
4. 環境変数が設定されているか確認:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`

---

## 🔧 診断手順

### ステップ1: ブラウザのコンソールで確認

1. **開発者ツール（F12）を開く**
2. **Consoleタブ**を開く
3. 以下のメッセージが表示されるか確認:
   - `✅ HTMLが読み込まれました` ← これが表示されない場合、HTMLが読み込まれていない
   - `✅ インラインスクリプトが実行されました` ← これが表示されない場合、インラインスクリプトがブロックされている
   - `✅ main.jsが読み込まれました` ← これが表示されない場合、main.jsが読み込まれていない

### ステップ2: Networkタブで確認

1. **Networkタブ**を開く
2. ページを再読み込み（F5）
3. 以下のリソースが読み込まれているか確認:
   - `index.html`（Status Code: 200）
   - `index-*.js`（JavaScriptファイル）
   - `index-*.css`（CSSファイル）
   - CDNリソース（Leaflet、UnoCSS）

**確認事項**:
- Status Codeが200か（404や500エラーでないか）
- リソースが読み込まれているか（赤い×印がついていないか）
- サイズが0バイトでないか

### ステップ3: エラーメッセージを確認

ConsoleタブまたはNetworkタブで以下のエラーが表示されていないか確認:

- `Failed to load resource` - リソースの読み込み失敗
- `404 Not Found` - ファイルが見つからない
- `CSP violation` - CSPエラー
- `CORS error` - CORSエラー

---

## ✅ 解決方法

### 方法1: Vercelの再デプロイ

1. Gitに変更をコミット・プッシュ
2. Vercelが自動的に再デプロイするのを待つ
3. 再度確認

### 方法2: ビルドの確認

ローカルでビルドして、`dist`フォルダにファイルが生成されているか確認:

```bash
npm run build
ls dist
```

### 方法3: 環境変数の確認

Vercelダッシュボードで環境変数が設定されているか確認

### 方法4: vercel.jsonの確認

`vercel.json`の設定が正しいか確認:

```json
{
  "buildCommand": "npm run build",
  "outputDirectory": "dist",
  "framework": "vite",
  "rewrites": [
    {
      "source": "/(.*)",
      "destination": "/index.html"
    }
  ]
}
```
