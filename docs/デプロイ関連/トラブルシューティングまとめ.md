# トラブルシューティングまとめ

このドキュメントは、Vercel上でのデプロイ時に発生した問題とその解決方法をまとめたものです。

## ✅ 解決済みの問題

### 1. テンプレートファイルパスの問題
- **問題**: 本番環境でテンプレートファイルが読み込めない
- **原因**: `/src/templates/...`パスが本番環境では存在しない
- **解決**: テンプレートファイルを`public/templates/`に移動し、パスを`/templates/...`に変更
- **詳細**: `テンプレートファイルパスの問題と解決方法.md`を参照

### 2. eval()エラーの問題
- **問題**: Vercel上で`eval()`がブロックされる
- **原因**: jQuery/Lightbox2が`eval()`を使用していた
- **解決**: jQuery/Lightbox2を削除し、Vanilla JavaScriptで画像拡大機能を実装
- **詳細**: `eval完全削除完了報告.md`を参照

### 3. CSPエラーの問題
- **問題**: Content Security Policyでリソースがブロックされる
- **原因**: CSP設定が不十分だった
- **解決**: `vercel.json`でCSPを適切に設定
- **詳細**: `CSP完全修正版.md`を参照

## 🔧 トラブルシューティング手順

### 1. 環境変数の確認
Vercelのダッシュボードで以下の環境変数が設定されているか確認：
- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_ANON_KEY`

### 2. ブラウザのコンソールでエラーを確認
1. Vercel上でアプリを開く
2. 開発者ツール（F12）を開く
3. Consoleタブでエラーメッセージを確認
4. Networkタブでリソースの読み込み状況を確認

### 3. ビルドログの確認
Vercelのダッシュボードでビルドログを確認し、エラーがないか確認
