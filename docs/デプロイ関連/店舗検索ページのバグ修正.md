# 店舗検索ページのバグ修正

## 🔍 問題の状況

### 報告された問題
- DBの情報を削除してから、ウェルカムページ→近くの店舗検索をするとエラーが出る
- 近くの店舗検索ページでリロードすると正しく追加される
- **つまり、ウェルカムページから遷移した時だけ正しく追加されていない**

### 問題の原因

1. **データベースへの追加処理の完了待ち**
   - `mergeStoresFromDBAndAPI`関数内で、APIから取得した店舗をデータベースに追加している
   - しかし、データベースへの追加が完了する前に、次の処理（`getStores(true)`）が実行されている可能性
   - これにより、追加された店舗が再取得時に取得されない

2. **エラーハンドリングの不足**
   - `addStoreIfNotExists`の結果を確認せずに処理を続行していた
   - エラーが発生しても詳細なログが記録されていなかった

## ✅ 修正内容

### 1. エラーハンドリングの改善

`mergeStoresFromDBAndAPI`関数内で、`addStoreIfNotExists`の結果を確認するように修正：

```javascript
const result = await addStoreIfNotExists({...});

if (result.success) {
    addResults.push({ store: apiStore, success: true, isNew: result.isNew });
} else {
    console.warn(`店舗追加失敗 (${apiStore.name}):`, result.error);
    addResults.push({ store: apiStore, success: false, error: result.error });
}
```

### 2. データベース反映の待機時間を追加

データベースへの追加処理が完了するまで少し待機するように修正：

```javascript
// データベースへの追加処理が完了するまで少し待機（データベースの反映を待つ）
if (addResults.some(r => r.success)) {
    await new Promise(resolve => setTimeout(resolve, 100));
}
```

### 3. 詳細なログ出力

エラーが発生した場合、詳細な情報をログに記録：

```javascript
console.error('エラー詳細:', {
    name: apiStore.name,
    latitude: apiStore.latitude,
    longitude: apiStore.longitude,
    error: error.message,
    stack: error.stack
});
```

### 4. API呼び出しのエラーハンドリング改善

API呼び出しのエラーハンドリングを改善し、詳細なエラー情報を記録：

```javascript
try {
    apiStores = await searchNearbyStores(userLocation.lat, userLocation.lng, 2000);
    console.log(`✅ APIから${apiStores.length}件の店舗を取得しました`);
} catch (error) {
    console.error('❌ 店舗検索エラー:', error);
    console.error('エラー詳細:', {
        message: error.message,
        stack: error.stack,
        lat: userLocation.lat,
        lng: userLocation.lng
    });
    apiStores = [];
}
```

## 📋 修正ファイル

- `src/pages/StoresPage.js`
  - `mergeStoresFromDBAndAPI`関数の改善
  - エラーハンドリングの改善
  - データベース反映の待機時間を追加

## 🎯 期待される動作

修正後、以下の動作が期待されます：

1. ウェルカムページから「近くの店舗検索」をクリック
2. APIから店舗を取得
3. データベースへの追加処理を実行
4. データベースへの反映を待機（100ms）
5. データベースの店舗を再取得
6. 統合された店舗リストを表示

これにより、ウェルカムページから遷移した時も、リロード時と同様に正しく店舗が追加されるようになります。

## 🔧 デバッグ情報

修正により、以下のログが出力されるようになりました：

- ✅ APIから取得した店舗数
- ⚠️ 店舗追加失敗時の警告
- ❌ エラー発生時の詳細なエラー情報

これらのログを確認することで、問題の原因を特定しやすくなります。
