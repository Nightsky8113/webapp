# Vercel上でのトラブルシューティングガイド

## 🔍 問題の症状

1. **ヘッダーが二重になっている**
2. **「読み込み中...」でフリーズする**

## ✅ 実施した修正

### 1. エラーハンドリングの強化
- ✅ 初期化タイムアウト（10秒）を追加
- ✅ 詳細なエラーログを追加
- ✅ グローバルエラーハンドラーの改善
- ✅ ページ描画エラーの詳細ログを追加

### 2. デバッグ情報の追加
- ✅ 各初期化ステップでコンソールログを追加
- ✅ エラー詳細（message, stack, name）をログ出力

## 🔧 Vercel上での確認事項

### 1. 環境変数の確認
Vercelのダッシュボードで以下の環境変数が設定されているか確認：

- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_ANON_KEY`

設定方法：
1. Vercelダッシュボード → プロジェクト → Settings → Environment Variables
2. 環境変数を追加
3. 再デプロイ

### 2. ブラウザのコンソールでエラーを確認
1. Vercel上でアプリを開く
2. 開発者ツール（F12）を開く
3. Consoleタブでエラーを確認
4. Networkタブでリソースの読み込み状況を確認

### 3. CSPの確認
- `vercel.json`のCSP設定が正しいか確認
- コンソールでCSPエラーが表示されていないか確認

## 📋 デバッグ手順

### ステップ1: コンソールエラーを確認
```
1. Vercel上でアプリを開く
2. F12で開発者ツールを開く
3. Consoleタブでエラーメッセージを確認
4. エラーメッセージをスクリーンショットまたはコピー
```

### ステップ2: ネットワークタブを確認
```
1. Networkタブを開く
2. ページを再読み込み
3. 失敗しているリソース（赤色）を確認
4. 特に重要なリソース：
   - /assets/index-*.js
   - /assets/index-*.css
   - Supabase API呼び出し
```

### ステップ3: 環境変数を確認
```
1. Vercelダッシュボード → プロジェクト → Settings
2. Environment Variablesを確認
3. 以下の変数が設定されているか確認：
   - VITE_SUPABASE_URL
   - VITE_SUPABASE_ANON_KEY
```

## 🚀 修正後の再デプロイ

1. 変更をコミット・プッシュ
   ```bash
   git add .
   git commit -m "Improve error handling and add timeout"
   git push
   ```

2. Vercelで自動再デプロイ
   - GitHubにプッシュすると、Vercelが自動的に再デプロイします

3. 動作確認
   - ブラウザのコンソールでエラーが表示されていないか確認
   - タイムアウトメッセージが表示されるか確認
   - エラーメッセージが表示されるか確認
