# テンプレートファイルパスの問題と解決方法

## 🔍 問題の原因

ローカル環境（`npm run dev`）では動作するが、Vercel上では動作しない原因は、**テンプレートファイルのパス**でした。

### 問題の詳細

1. **開発環境（ローカル）**:
   - Viteの開発サーバーは`/src/`ディレクトリを提供
   - `/src/templates/pages/home-page.html`にアクセス可能

2. **本番環境（Vercel）**:
   - Viteはビルド時に`src/`ディレクトリをバンドルに含めるが、静的ファイルとしてコピーしない
   - `/src/templates/...`というパスは存在しない
   - テンプレートファイルが読み込めない

---

## ✅ 解決方法

### 1. テンプレートファイルを`public/`に移動

Viteは`public/`ディレクトリ内のファイルをビルド時に`dist/`にコピーします。

```bash
Copy-Item -Path "src/templates" -Destination "public/templates" -Recurse -Force
```

### 2. すべてのテンプレートパスを修正

すべてのファイルでテンプレートパスを変更：

**変更前:**
```javascript
loadAndRenderTemplate('/src/templates/pages/home-page.html', templateData)
```

**変更後:**
```javascript
loadAndRenderTemplate('/templates/pages/home-page.html', templateData)
```

### 3. 修正したファイル

- ✅ `src/pages/HomePage.js`
- ✅ `src/pages/SearchResultsPage.js`
- ✅ `src/pages/StoresPage.js`
- ✅ `src/pages/StoreDetailPage.js`
- ✅ `src/pages/AdminUploadPage.js`
- ✅ `src/components/StoreCard.js`
- ✅ `src/pages/GenreStoresPage.js`
- ✅ `src/components/GenreCard.js`
- ✅ `src/pages/GenrePage.js`
