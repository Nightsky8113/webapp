# スクリプトタグの問題確認

## 🔍 問題の確認

- HTMLは読み込まれている
- インラインスクリプトは実行されている
- アプリの初期化は完了している
- しかし、正常に動作していない

## 📋 確認が必要な点

1. **`dist/index.html`に`<script type="module" src="/src/main.js"></script>`が存在するか**
2. **Viteが生成したバンドルファイル（`/assets/index-*.js`）が正しく読み込まれているか**
3. **ビルド後のHTMLとソースのHTMLが一致しているか**
