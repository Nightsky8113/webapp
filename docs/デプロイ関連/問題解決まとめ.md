# 問題解決まとめ

## 🔍 発見された問題

ローカル環境（`npm run dev`）では動作するが、Vercel上では動作しない原因は、**テンプレートファイルのパス**でした。

### 原因

1. **開発環境**: Viteの開発サーバーが`/src/`ディレクトリを提供するため、`/src/templates/...`にアクセス可能
2. **本番環境**: Viteは`src/`ディレクトリを静的ファイルとしてコピーしないため、`/src/templates/...`というパスは存在しない
3. **結果**: テンプレートファイルが読み込めず、ページが表示されない

---

## ✅ 実施した修正

### 1. テンプレートファイルを`public/`に移動

Viteは`public/`ディレクトリ内のファイルをビルド時に`dist/`にコピーします。

```bash
Copy-Item -Path "src/templates" -Destination "public/templates" -Recurse -Force
```

### 2. すべてのテンプレートパスを修正

すべてのファイルでテンプレートパスを`/src/templates/...`から`/templates/...`に変更。

### 3. 修正したファイル（9ファイル）

- ✅ `src/pages/HomePage.js`
