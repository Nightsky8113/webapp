# AIのAPI代替案調査

OpenAI APIの無料枠が終了したため、OCR結果の構造化処理に使用できる無料または無料枠があるAIのAPIを調査しました。

## 📊 調査結果

### 1. Google Gemini API（推奨）⭐️

**無料枠**:
- **個人開発・テスト目的**: ほぼ無制限に無料
- APIキー取得: Google AI Studioから簡単に取得可能

**特徴**:
- マルチモーダル対応（テキスト、画像、音声など）
- 日本語対応
- 構造化データの生成に適している

**料金**（無料枠超過時）:
- Gemini 1.5 Flash: 入力$0.075/1Mトークン、出力$0.30/1Mトークン
- Gemini 1.5 Pro: 入力$1.25/1Mトークン、出力$5.00/1Mトークン

**コンテスト用途での見積もり**:
- 1チラシあたり: 約2,000-5,000トークン（入力）
- 120回の処理: 約240,000-600,000トークン
- 無料枠内で完全対応可能 ✅

**参考**: 
- [Google AI Studio](https://aistudio.google.com/)
- コンテスト用途であれば、ほぼ無制限に無料で利用可能

---

### 2. Anthropic Claude API

**無料枠**:
- **継続的な無料枠**: 月$10相当（要確認）
- 新規ユーザー向けにAPIコール数に制限あり

**特徴**:
- 長文処理に優れている
- 安全性と倫理性を重視
- 日本語対応

**料金**（無料枠超過時）:
- Claude 3 Haiku: 入力$0.25/1Mトークン、出力$1.25/1Mトークン
- Claude 3 Sonnet: 入力$3.00/1Mトークン、出力$15.00/1Mトークン

**コンテスト用途での見積もり**:
- 月$10相当の無料枠があれば、約40,000トークンの入力が可能
- コンテスト用途（120回）では、月$10で対応可能 ✅

**参考**:
- [Anthropic Console](https://console.anthropic.com/)
- 継続的な無料枠がある場合、長期的に使用可能

---

### 3. Hugging Face API

**無料枠**:
- 一部モデルが無料で使用可能
- レート制限あり（低トラフィック向け）

**特徴**:
- オープンソースモデル多数
- テキスト生成、分類、翻訳など多様な機能

**注意点**:
- 無料プランにはレート制限がある
- 主に低トラフィックのアプリや開発作業向け

**参考**:
- [Hugging Face Inference API](https://huggingface.co/docs/api-inference/index)

---

### 4. Cohere API

**無料枠**:
- 無料プランあり
- APIキー取得で利用可能

**特徴**:
- テキスト生成、分類、検索などに特化
- 自然言語処理に優れている

**参考**:
- [Cohere Platform](https://cohere.com/)

---

## 💡 推奨案

### 最優先: Google Gemini API ⭐️

**理由**:
1. ✅ **ほぼ無制限の無料枠**（個人開発・テスト目的）
2. ✅ **日本語対応**
3. ✅ **構造化データの生成に適している**
4. ✅ **APIキー取得が簡単**（Google AI Studio）
5. ✅ **コンテスト用途に最適**

**実装の容易さ**: ⭐⭐⭐⭐⭐（非常に簡単）

---

### 代替案: Anthropic Claude API

**理由**:
1. ✅ **継続的な無料枠**（月$10相当）
2. ✅ **日本語対応**
3. ✅ **長文処理に優れている**

**注意点**:
- 無料枠の詳細を確認する必要がある

**実装の容易さ**: ⭐⭐⭐⭐（簡単）

---

## 📝 結論

### コンテスト用途では Google Gemini API を推奨

**理由**:
- ほぼ無制限の無料枠（個人開発・テスト目的）
- コンテスト期間中の使用量を心配する必要がない
- 実装が簡単
- 日本語対応

### 実装計画

1. ✅ **Google Gemini APIに切り替え**（推奨）
2. ⚠️ Anthropic Claude APIも選択肢として検討可能
3. ⚠️ Hugging Face APIはレート制限があるため、コンテスト用途には不向き
