# 外部API統合 - 環境変数設定ガイド

Google Cloud Vision APIとOpenAI APIの環境変数を設定する手順です。

## 📋 必要な環境変数

以下の2つの環境変数が必要です：

1. `VITE_GOOGLE_CLOUD_VISION_API_KEY` - Google Cloud Vision APIキー
2. `VITE_OPENAI_API_KEY` - OpenAI APIキー

---

## 🔑 Google Cloud Vision APIキーの取得

### 1. Google Cloud Platformアカウントを作成

1. [Google Cloud Platform](https://cloud.google.com/)にアクセス
2. 「無料で始める」をクリック
3. アカウント情報を入力して登録
4. **$300の無料クレジットが付与されます**（90日間有効）

### 2. プロジェクトを作成

1. [Google Cloud Console](https://console.cloud.google.com/)にログイン
2. プロジェクト選択 → 「新しいプロジェクト」をクリック
3. プロジェクト名を入力（例: `flyer-search-app`）
4. 「作成」をクリック

### 3. Vision APIを有効化

1. 「APIとサービス」→「ライブラリ」を開く
2. 「Cloud Vision API」を検索
3. 「Cloud Vision API」を選択
4. 「有効にする」をクリック

### 4. APIキーを作成

1. 「APIとサービス」→「認証情報」を開く
2. 「認証情報を作成」→「APIキー」を選択
3. APIキーが生成される
4. **重要**: APIキーをクリックして設定を開く
   - 「アプリケーションの制限」: 「HTTPリファラー（ウェブサイト）」
   - 「リファラー」: 自分のドメインを追加（例: `https://your-domain.com/*`）
   - 「保存」をクリック

### 5. 環境変数に設定

`.env`ファイルに追加：

```env
VITE_GOOGLE_CLOUD_VISION_API_KEY=your-api-key-here
```

---

## 🤖 OpenAI APIキーの取得

### 1. OpenAIアカウントを作成

1. [OpenAI Platform](https://platform.openai.com/)にアクセス
2. 「Sign up」をクリックしてアカウントを作成
3. **$5の無料クレジットが付与されます**（30日間有効）

### 2. APIキーを作成

1. [API Keys](https://platform.openai.com/api-keys)ページにアクセス
2. 「Create new secret key」をクリック
3. キー名を入力（例: `flyer-search-app`）
4. 「Create secret key」をクリック
5. **重要**: APIキーは一度しか表示されないため、必ずコピーして保存してください

### 3. 環境変数に設定

`.env`ファイルに追加：

```env
VITE_OPENAI_API_KEY=your-api-key-here
```

---

## 📝 環境変数ファイルの設定

### 開発環境（`.env`）

プロジェクトルートに`.env`ファイルを作成：

```env
# Supabase
VITE_SUPABASE_URL=your-supabase-url
VITE_SUPABASE_ANON_KEY=your-supabase-anon-key

# Google Cloud Vision API
VITE_GOOGLE_CLOUD_VISION_API_KEY=your-google-cloud-vision-api-key

# OpenAI API
VITE_OPENAI_API_KEY=your-openai-api-key
```

### 本番環境（Vercel）

1. [Vercel Dashboard](https://vercel.com/dashboard)にログイン
2. プロジェクトを選択
3. 「Settings」→「Environment Variables」を開く
4. 以下の環境変数を追加：
   - `VITE_GOOGLE_CLOUD_VISION_API_KEY`
   - `VITE_OPENAI_API_KEY`
5. 「Save」をクリック
6. 変更を反映するために再デプロイ

## 🔒 セキュリティ注意事項

### ⚠️ 重要な注意点

1. **APIキーは絶対に公開リポジトリにコミットしない**
   - `.env`ファイルは`.gitignore`に追加済み
   - 誤ってコミットした場合は、すぐにキーを再生成する

2. **APIキーの制限を設定する**
   - Google Cloud: HTTPリファラー制限を設定
   - OpenAI: 使用量上限を設定

3. **使用量を監視する**
   - Google Cloud Consoleで使用量を確認
   - OpenAI Dashboardで使用量を確認
   - 異常な使用量がないか定期的にチェック

## 💰 無料枠とコスト管理

### Google Cloud Vision API

- **無料クレジット**: $300（90日間）
- **料金**: 1,000リクエストあたり$1.50
- **コンテスト用途**: 約120回の処理で$0.18程度

### OpenAI API

- **無料クレジット**: $5（30日間）
- **料金**: GPT-3.5 Turbo使用で約$0.001/1Kトークン
- **コンテスト用途**: 約120回の処理で$0.40程度

### 使用量上限の設定

#### Google Cloud

1. [Quotas](https://console.cloud.google.com/apis/api/vision.googleapis.com/quotas)ページにアクセス
2. 「TEXT_DETECTION」の使用量を確認
3. 必要に応じてアラートを設定

#### OpenAI

1. [Usage Limits](https://platform.openai.com/account/limits)ページにアクセス
2. 「Hard limit」を設定（例: $10/月）
3. 使用量が上限に近づいたら通知を受け取る

## ✅ 動作確認

環境変数を設定したら、以下の手順で動作確認：

1. `.env`ファイルが正しく設定されているか確認
2. 開発サーバーを再起動（環境変数の変更を反映）
3. 管理者ページで画像をアップロード
4. 「OCR処理を実行する」にチェックを入れる
5. アップロード後にOCR処理が実行されるか確認
