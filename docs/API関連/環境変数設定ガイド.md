# 外部API統合 - 環境変数設定ガイド

Google Cloud Vision APIとGoogle Gemini APIの環境変数を設定する手順です。

## 📋 必要な環境変数

以下の2つの環境変数が必要です：

1. `VITE_GOOGLE_CLOUD_VISION_API_KEY` - Google Cloud Vision APIキー（OCR処理用）
2. `VITE_GOOGLE_GEMINI_API_KEY` - Google Gemini APIキー（OCR結果の構造化用）

---

## 🔑 Google Cloud Vision APIキーの取得

### 1. Google Cloud Platformアカウントを作成

1. [Google Cloud Platform](https://cloud.google.com/)にアクセス
2. 「無料で始める」をクリック
3. アカウント情報を入力して登録
4. **$300の無料クレジットが付与されます**（90日間有効）

### 2. プロジェクトを作成

1. [Google Cloud Console](https://console.cloud.google.com/)にログイン
2. プロジェクト選択 → 「新しいプロジェクト」をクリック
3. プロジェクト名を入力（例: `flyer-search-app`）
4. 「作成」をクリック

### 3. Vision APIを有効化

1. 「APIとサービス」→「ライブラリ」を開く
2. 「Cloud Vision API」を検索
3. 「Cloud Vision API」を選択
4. 「有効にする」をクリック

### 4. APIキーを作成

1. 「APIとサービス」→「認証情報」を開く
2. 「認証情報を作成」→「APIキー」を選択
3. APIキーが生成される
4. **重要**: APIキーをクリックして設定を開く
   - 「アプリケーションの制限」: 「HTTPリファラー（ウェブサイト）」
   - 「リファラー」: 自分のドメインを追加（例: `https://your-domain.com/*`）
   - 「保存」をクリック

### 5. 環境変数に設定

`.env`ファイルに追加：

```env
VITE_GOOGLE_CLOUD_VISION_API_KEY=your-api-key-here
```

---

## 🤖 Google Gemini APIキーの取得

### 1. Google AI Studioアカウントを作成

1. [Google AI Studio](https://makersuite.google.com/app/apikey)にアクセス
2. Googleアカウントでログイン
3. 「Create API Key」をクリック
4. プロジェクトを選択（または新規作成）
5. APIキーが生成される

### 2. APIキーをコピー

1. 生成されたAPIキーをコピー
2. **重要**: APIキーは一度しか表示されない場合があるため、必ずコピーして保存してください

### 3. 環境変数に設定

`.env`ファイルに追加：

```env
VITE_GOOGLE_GEMINI_API_KEY=your-gemini-api-key-here
```

### 4. 無料枠について

- ✅ **個人開発・テスト目的でほぼ無制限に無料**
- ✅ 1分あたり15リクエスト、1日あたり1,500リクエストまで無料
- ✅ コンテスト用途なら完全無料で運用可能

---

## 📝 環境変数ファイルの設定

### 開発環境（`.env`）

プロジェクトルートに`.env`ファイルを作成：

```env
# Supabase
VITE_SUPABASE_URL=your-supabase-url
VITE_SUPABASE_ANON_KEY=your-supabase-anon-key

# Google Cloud Vision API
VITE_GOOGLE_CLOUD_VISION_API_KEY=your-google-cloud-vision-api-key

# Google Gemini API
VITE_GOOGLE_GEMINI_API_KEY=your-google-gemini-api-key
```

### 本番環境（Vercel）

1. [Vercel Dashboard](https://vercel.com/dashboard)にログイン
2. プロジェクトを選択
3. 「Settings」→「Environment Variables」を開く
4. 以下の環境変数を追加：
   - `VITE_GOOGLE_CLOUD_VISION_API_KEY`
   - `VITE_GOOGLE_GEMINI_API_KEY`
5. 「Save」をクリック
6. 変更を反映するために再デプロイ

---

## 🔒 セキュリティ注意事項

### ⚠️ 重要な注意点

1. **APIキーは絶対に公開リポジトリにコミットしない**
   - `.env`ファイルは`.gitignore`に追加済み
   - 誤ってコミットした場合は、すぐにキーを再生成する

2. **APIキーの制限を設定する**
   - Google Cloud Vision API: HTTPリファラー制限を設定
   - Google Gemini API: 使用量上限を設定（Google AI Studioで設定可能）

3. **使用量を監視する**
   - Google Cloud ConsoleでVision APIの使用量を確認
   - Google AI StudioでGemini APIの使用量を確認
   - 異常な使用量がないか定期的にチェック

## 💰 無料枠とコスト管理

### Google Cloud Vision API

- **無料クレジット**: $300（90日間）
- **月額無料枠**: 毎月1,000リクエストまで無料
- **料金**: 1,000リクエストあたり$1.50
- **コンテスト用途**: 約120回の処理で完全無料（無料枠内）

### Google Gemini API

- **無料枠**: 個人開発・テスト目的でほぼ無制限に無料
- **制限**: 1分あたり15リクエスト、1日あたり1,500リクエストまで無料
- **コンテスト用途**: 完全無料で運用可能

### 使用量上限の設定

#### Google Cloud

1. [Quotas](https://console.cloud.google.com/apis/api/vision.googleapis.com/quotas)ページにアクセス
2. 「TEXT_DETECTION」の使用量を確認
3. 必要に応じてアラートを設定

#### Google Gemini API

1. [Google AI Studio](https://makersuite.google.com/app/apikey)にアクセス
2. APIキーの設定ページで使用量を確認
3. 必要に応じて使用量上限を設定

## ✅ 動作確認

環境変数を設定したら、以下の手順で動作確認：

1. `.env`ファイルが正しく設定されているか確認
2. 開発サーバーを再起動（環境変数の変更を反映）
3. 管理者ページで画像をアップロード
4. 「OCR処理を実行する」にチェックを入れる
5. アップロード後にOCR処理が実行されるか確認
