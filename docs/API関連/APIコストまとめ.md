# Google Places API 無料利用可能範囲（2025年最新）

## 📊 結論：現在の検索条件での無料利用可能範囲

### ✅ 無料枠: **毎月5,000回まで**

**2025年3月1日以降の新料金体系**:
- Places API (Nearby Search) は **Proカテゴリ**
- **毎月5,000回まで無料**
- 超過分: **$32.00 / 1,000リクエスト**

---

## 🎯 実装パターン別の無料利用可能範囲

### パターン1: オプション機能（推奨）⭐️

**実装内容**:
- 「位置情報から探す」をクリックしたときのみPlaces APIを呼び出す
- 検索結果を30分間キャッシュ
- デフォルトはデータベースの店舗のみ表示

**1ユーザーあたりの使用量**:
- 1回の検索 = 1リクエスト
- 1日あたり: 0.5-1回検索（想定）
- 1か月あたり: 15-30リクエスト/ユーザー

**無料枠内で運用可能なユーザー数**:

| 1日あたりの検索回数 | 1か月あたりのリクエスト | 最大ユーザー数（無料枠内） |
|------------------|----------------------|------------------------|
| 0.5回/日 | 15リクエスト/ユーザー | **約333ユーザー** ✅ |
| 1回/日 | 30リクエスト/ユーザー | **約166ユーザー** ✅ |
| 2回/日 | 60リクエスト/ユーザー | **約83ユーザー** ⚠️ |

**結論**: 
- ✅ **約160-170ユーザー/日まで無料枠内で運用可能**
- ✅ **キャッシュ機能により、実際はもっと多くのユーザーに対応可能**

---

### パターン2: 自動検索（非推奨）

**実装内容**:
- ページを開くたびに自動でPlaces APIを呼び出す
- キャッシュなし

**1ユーザーあたりの使用量**:
- ページ訪問1回 = 1リクエスト
- 1日あたり: 10-20回訪問（想定）
- 1か月あたり: 300-600リクエスト/ユーザー

**無料枠内で運用可能なユーザー数**:
- **約8-16ユーザー/日まで**（非常に少ない）❌

**結論**: この方法では無料枠をすぐに超えるため、**非推奨**

---

## 💡 無料枠内で安全に運用するための推奨事項

### 1. オプション機能として実装（必須）

✅ ユーザーが選択できるようにする
- デフォルト: データベースの店舗のみ表示
- オプション: 「近くのスーパーを検索」ボタン

### 2. キャッシュ機能を実装（必須）

✅ 30分間キャッシュ
- 同じ位置情報（±100m以内）の場合はキャッシュを使用
- リクエスト数を約80-90%削減

### 3. リクエスト制限を実装（推奨）

✅ 1ユーザーあたり1日3回まで
- 異常な使用を防止

### 4. モニタリングを実装（推奨）

✅ 使用量を追跡
- 無料枠に近づいたら警告
