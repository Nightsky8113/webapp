## 🔍 実装の詳細

### 使用しているAPI

**Overpass API** - OpenStreetMapのデータを検索するAPI
- **URL**: `https://overpass-api.de/api/interpreter`
- **コスト**: **完全無料**（コスト0円）
- **データソース**: OpenStreetMap（コミュニティが編集する無料の地図データ）

### 実装コード（`js/script.js`）

```javascript
// 68-118行目: loadSupermarkets関数
async function loadSupermarkets(lat, lon) {
  const radius = 5000; // 5km以内

  // Overpass API用のクエリを作成
  const query = `
    [out:json];
    (
      node["shop"="supermarket"](around:${radius},${lat},${lon});
      way["shop"="supermarket"](around:${radius},${lat},${lon});
      relation["shop"="supermarket"](around:${radius},${lat},${lon});
      node["name"="ハローズ"](around:${radius},${lat},${lon});
      node["name"="コープ"](around:${radius},${lat},${lon});
      node["name"="イオン"](around:${radius},${lat},${lon});
    );
    out center;
  `;

  // Overpass APIにリクエストを送信
  const url = "https://overpass-api.de/api/interpreter?data=" + encodeURIComponent(query);
  const res = await fetch(url);
  const data = await res.json(); // JSON形式で結果を取得

  // 取得したデータを処理して店舗リストを作成
  // ...
}
```

## 📊 実装の流れ

### 1. 位置情報の取得
- `navigator.geolocation.getCurrentPosition()`で現在地を取得
- 取得成功後、`loadSupermarkets()`を呼び出す

### 2. 店舗検索（Overpass API）
- 現在地から5km以内のスーパーマーケットを検索
- 検索条件:
  - `shop=supermarket`のタグが付いた店舗
  - 特定の店舗名（ハローズ、コープ、イオン）

### 3. データの処理
- APIからJSON形式で結果を取得
- 各店舗の距離を計算
- 地図にマーカーを表示

### 4. 店舗情報の表示
- `Supermarkets`配列に店舗情報を格納
- `item-search.js`で店舗情報を使用して特売情報を表示

## 🆚 Google Places APIとの比較

| 項目 | Overpass API（サンプルで使用） | Google Places API |
|------|------------------------------|-------------------|
| **コスト** | **完全無料** ✅ | 月5,000回まで無料、以降有料 ⚠️ |
| **データソース** | OpenStreetMap | Google Maps |
| **データ精度** | コミュニティ編集（地域により差あり） | 高精度 ✅ |
| **日本語対応** | 限定的 ⚠️ | 完全対応 ✅ |
| **実装の複雑さ** | やや複雑（クエリ言語を理解する必要） | シンプル ✅ |
| **レスポンス速度** | やや遅い（数秒かかる場合あり） | 高速 ✅ |
| **店舗情報の詳細度** | 限定的（名前、位置のみ） | 豊富（営業時間、評価など） ✅ |

## 💡 サンプルコードの特徴

### メリット
- ✅ **完全無料** - コストがかからない
- ✅ **実装済み** - 動作するコードが既にある
- ✅ **OpenStreetMapのデータ** - 世界中のデータにアクセス可能

### デメリット
- ⚠️ **データの精度** - 地域によっては店舗情報が不足している可能性
- ⚠️ **日本語対応** - 店舗名が英語表記の可能性
- ⚠️ **レスポンス速度** - APIサーバーの負荷により遅い場合がある
- ⚠️ **詳細情報が少ない** - 営業時間、評価などの情報は取得できない
