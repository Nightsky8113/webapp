# Google Cloud Vision APIキー取得手順

Google Cloud Vision APIキーを取得する詳細な手順を説明します。

---

## 📋 前提条件

- Googleアカウントが必要です
- クレジットカード情報が必要な場合があります（無料クレジットが使用されます）

---

## 🔑 手順1: Google Cloud Platformアカウントを作成

### 1-1. Google Cloud Platformにアクセス

1. ブラウザで以下のURLにアクセス：
   - **URL**: https://cloud.google.com/

2. 「**無料で始める**」または「**Get started for free**」をクリック

3. Googleアカウントでログイン（まだログインしていない場合）

### 1-2. アカウント情報を入力

1. **国/地域**を選択（日本を選択）
2. **利用規約**に同意
3. **クレジットカード情報を入力**（必須）
   - ⚠️ **注意**: 無料トライアル中は自動課金されません
   - 無料クレジット（$300）が使用されます
   - 無料クレジットが切れても、明示的に有効化しない限り課金されません

4. 「**無料トライアルを開始**」をクリック

### 1-3. 無料クレジットの確認

- ✅ **$300の無料クレジット**が付与されます（90日間有効）
- ✅ 90日間は無料で使用できます

---

## 🏗️ 手順2: プロジェクトを作成

### 2-1. Google Cloud Consoleにアクセス

1. ブラウザで以下のURLにアクセス：
   - **URL**: https://console.cloud.google.com/

2. Googleアカウントでログイン

### 2-2. 新しいプロジェクトを作成

1. 画面上部の**プロジェクト選択**ドロップダウンをクリック
   - 「**プロジェクトを選択**」または「**Select a project**」と表示されている部分

2. 「**新しいプロジェクト**」または「**NEW PROJECT**」をクリック

3. プロジェクト情報を入力：
   - **プロジェクト名**: 例）`flyer-search-app`、`ocr-app` など
   - **組織**: （省略可能）
   - **場所**: （省略可能）

4. 「**作成**」または「**CREATE**」をクリック

5. プロジェクトが作成されるまで待つ（数秒かかります）

6. 作成されたプロジェクトを選択

---

## 🔧 手順3: Cloud Vision APIを有効化

### 3-1. APIライブラリを開く

1. 左側のメニューから以下の順番でクリック：
   - 「**APIとサービス**」（API & Services）
   - 「**ライブラリ**」（Library）

   **または**、直接以下のURLにアクセス：
   - **URL**: https://console.cloud.google.com/apis/library

### 3-2. Cloud Vision APIを検索

1. 検索ボックスに「**Cloud Vision API**」と入力

2. 「**Cloud Vision API**」を選択
   - Google Cloudによって提供されるAPIです

### 3-3. APIを有効化

1. 「**有効にする**」または「**ENABLE**」をクリック

2. APIが有効化されるまで待つ（数秒かかります）

3. 有効化が完了すると、APIのダッシュボードが表示されます

---

## 🔑 手順4: APIキーを作成

### 4-1. 認証情報ページを開く

1. 左側のメニューから以下の順番でクリック：
   - 「**APIとサービス**」（API & Services）
   - 「**認証情報**」（Credentials）

   **または**、直接以下のURLにアクセス：
   - **URL**: https://console.cloud.google.com/apis/credentials

### 4-2. APIキーを作成

1. 画面上部の「**認証情報を作成**」または「**CREATE CREDENTIALS**」をクリック

2. ドロップダウンメニューから「**APIキー**」（API key）を選択

3. APIキーが自動生成されます
   - ⚠️ **重要**: この時点でAPIキーが表示されます
   - 一度閉じると、APIキーの文字列は再表示できません
   - **必ずコピーして安全な場所に保存してください**

4. 「**コピー**」をクリックしてAPIキーをコピー

5. 「**閉じる**」をクリック

---

## 🔒 手順5: APIキーの制限を設定（重要・推奨）

### 5-1. APIキーの設定を開く

1. 認証情報ページで、作成したAPIキーをクリック
   - APIキーの名前をクリック

### 5-2. アプリケーションの制限を設定

1. 「**アプリケーションの制限**」（Application restrictions）セクションで：
   - 「**HTTPリファラー（ウェブサイト）**」（HTTP referrers (web sites)）を選択

2. 「**ウェブサイトのリファラー**」（Website referrers）に以下を追加：
   ```
   https://your-domain.com/*
   https://*.vercel.app/*
   http://localhost:*
   ```
   
   **注意**: `your-domain.com` を実際のドメインに置き換えてください
   
   例：
   ```
   https://my-app.vercel.app/*
   http://localhost:5173/*
   http://localhost:3000/*
   ```

### 5-3. APIの制限を設定

1. 「**APIの制限**」（API restrictions）セクションで：
   - 「**キーを制限する**」（Restrict key）を選択
   - 「**Cloud Vision API**」を選択
   - その他のAPIは選択しない

2. 「**保存**」（SAVE）をクリック

3. 変更が保存されるまで待つ（数秒かかります）

---

## 💾 手順6: 環境変数に設定

### 6-1. .envファイルを作成または編集

1. プロジェクトのルートディレクトリに `.env` ファイルを作成（まだ存在しない場合）

2. 以下の内容を追加：

```env
VITE_GOOGLE_CLOUD_VISION_API_KEY=あなたのAPIキーをここに貼り付け
```

**例**:
```env
VITE_GOOGLE_CLOUD_VISION_API_KEY=AIzaSyAbc123Def456Ghi789Jkl012Mno345Pqr
```

### 6-2. 開発サーバーを再起動

環境変数を変更したら、開発サーバーを再起動する必要があります：

```bash
# 現在のサーバーを停止（Ctrl + C）
# 再度起動
npm run dev
```

## ✅ 動作確認

### 確認方法

1. 管理者ページ（`/admin/upload`）にアクセス
2. 画像をアップロード
3. 「OCR処理を実行する」にチェックを入れる
4. アップロード後にOCR処理が実行されることを確認

### エラーが発生した場合

- APIキーが正しく設定されているか確認
- 開発サーバーを再起動したか確認
- ブラウザのコンソールでエラーメッセージを確認

---

## 📝 本番環境（Vercel）での設定

### Vercelでの環境変数設定

1. [Vercel Dashboard](https://vercel.com/dashboard)にログイン

2. プロジェクトを選択

3. 「**Settings**」タブをクリック

4. 「**Environment Variables**」をクリック

5. 以下の環境変数を追加：
   - **Key**: `VITE_GOOGLE_CLOUD_VISION_API_KEY`
   - **Value**: あなたのAPIキー

6. 「**Save**」をクリック

7. 変更を反映するために再デプロイ：
   - 「**Deployments**」タブから最新のデプロイを選択
   - 「**Redeploy**」をクリック

## ⚠️ 重要な注意事項

### セキュリティ

1. **APIキーは絶対に公開リポジトリにコミットしない**
   - `.env`ファイルは`.gitignore`に追加済み
   - 誤ってコミットした場合は、すぐにキーを再生成する

2. **APIキーの制限を設定する**
   - HTTPリファラー制限を設定
   - 使用するAPIのみを許可

3. **使用量を監視する**
   - Google Cloud Consoleで使用量を確認
   - 異常な使用量がないか定期的にチェック

### 無料クレジットについて

- 90日間有効
- 使用量が$300に達するか、90日が経過すると無料トライアルが終了
- 終了後も、明示的に有効化しない限り自動課金されません

## 🆘 よくある問題

### Q1: APIキーが見つからない

**A**: 認証情報ページで再度確認してください。見つからない場合は、新しいAPIキーを作成してください。

### Q2: APIが有効化されない

**A**: 
- プロジェクトが正しく選択されているか確認
- 少し時間をおいてから再度試してください
- ブラウザのキャッシュをクリアしてください

### Q3: エラーが発生する

**A**:
- APIキーが正しく設定されているか確認
- 開発サーバーを再起動してください
- ブラウザのコンソールでエラーメッセージを確認してください
