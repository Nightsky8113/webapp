# コンテスト用API無料枠確認結果

コンテスト用途での外部API統合（OCR処理）が無料枠で可能かどうかの確認結果です。

## ✅ 結論：無料枠で十分対応可能

コンテスト用途（テスト・審査のみ）であれば、**無料クレジットだけで運用可能**です。

## 📊 想定使用量（コンテスト用途）

### 使用シナリオ

| 期間 | 使用内容 | 使用量 |
|------|---------|--------|
| **開発・テスト時** | チラシ画像のOCR処理 | 5-10回 |
| **審査時** | 審査員による試用・新規チラシアップロード | 10-25回 |

## 🔍 各APIの無料枠

### 1. Google Cloud Vision API

#### 無料枠

- ✅ **初回登録時に$300の無料クレジット**（90日間有効）
- ✅ **月額無料枠**: 毎月1,000リクエストまで無料（要確認）

#### 料金体系

- テキスト検出（OCR）: **1,000リクエストあたり$1.50**
- 画像ラベル検出: 1,000リクエストあたり$1.50

#### コンテスト用途でのコスト見積もり

| 期間 | 使用量 | コスト |
|------|--------|--------|
| 1か月目 | 40回 | **$0**（無料クレジット内） |
| 2か月目 | 40回 | **$0.06**（$300クレジット内） |
| 3か月目 | 40回 | **$0.06**（$300クレジット内） |
| **合計** | **120回** | **$0.18**（無料クレジット内で完全無料） |

**結論**: 
- ✅ **$300の無料クレジットで約200,000回のOCR処理が可能**
- ✅ **コンテスト用途（120回）なら完全無料で運用可能**

### 2. OpenAI API

#### 料金体系（GPT-4 Vision）

## 🚨 注意点と対策

### 1. クレジットカード登録が必要

両サービスともクレジットカード登録が必要ですが：
- ✅ Google Cloud: $300の無料クレジットがあるため、実際の課金は発生しない
- ⚠️ OpenAI: クレジットが切れると$0.40程度の課金が発生する可能性がある

### 2. 安全対策

#### 使用量の上限設定

**Google Cloud**:
```
1. Cloud Console → API & Services → Quotas
2. Vision API の使用量上限を設定（例: 200リクエスト/日）
3. アラートを設定（80%に達したら通知）
```

**OpenAI**:
```
1. OpenAI Dashboard → Usage → Usage Limits
2. 使用量上限を設定（例: $10/月）
3. アラートを設定（80%に達したら通知）
```

#### 定期監視

- **1日1回**: 使用量を確認
- **週1回**: コスト見積もりを確認
- **月1回**: 請求額を確認

### 3. テスト環境での検証

- 本番環境に影響を与えないよう、テスト環境で十分に検証
- 使用量を最小限に抑える（サンプル画像1-2枚でテスト）
