# コンテスト用API無料枠調査

コンテスト用途での外部API統合（OCR処理）が無料枠で可能かどうかを調査します。

1. **開発・テスト時**

3. **合計使用量（1か月間）**

### コンテスト期間中の使用量

- コンテスト期間: 1-3か月（想定）
- 1か月あたりのOCR処理: **約20-40回**
- 3か月間の合計: **約60-120回**

## 🔍 各APIの無料枠調査

### 1. Google Cloud Vision API

**調査中...**

#### 無料枠（一般情報）
- 初回登録時に$300の無料クレジットが付与される（90日間有効）
- その後、毎月の無料枠: 調査中

#### 料金体系（参考）
- テキスト検出（OCR）: 1,000リクエストあたり$1.50
- 画像ラベル検出: 1,000リクエストあたり$1.50

#### コンテスト用途での見積もり
- 1か月あたり40回のOCR処理
- 料金: 40 ÷ 1,000 × $1.50 = **$0.06/月**
- 無料クレジット$300で: 300 ÷ 0.06 = **約5,000か月分相当**

**結論**: 
- ✅ **初回$300の無料クレジットがあれば、コンテスト期間中は完全無料**
- ✅ **無料クレジットが切れても、月額$0.06程度で運用可能**

## 🚨 注意点

### 1. 無料クレジットの有効期限
- Google Cloud: 90日間（3か月）
- OpenAI: 通常30日間（要確認）

### 2. クレジットカード登録
- 両サービスともクレジットカード登録が必要
- 無料枠を超えた場合、自動課金される可能性があるため、**使用量を監視**する必要があります

### 3. 安全対策
- **使用量の上限設定**（アラート設定）
- **定期監視**（1日1回、使用量を確認）
- **テスト環境での検証**（本番環境に影響を与えない）
